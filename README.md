# NLP Sentiment Analyser — DistilBERT vs Baseline Models

A production-quality NLP pipeline that fine-tunes **DistilBERT** on the Stanford
Sentiment Treebank (SST-2) dataset and benchmarks it against two classical
baselines — Logistic Regression and LinearSVC — both backed by TF-IDF
vectorisation. The project is packaged with a Streamlit web app for interactive
inference, a full evaluation suite with visualisations, and a pytest test suite,
making it a complete, end-to-end demonstration of modern applied NLP.

---

## Key Results

| Model               | Accuracy | F1 Score (macro) |
|---------------------|----------|------------------|
| DistilBERT          | ~0.930   | ~0.930           |
| Logistic Regression | ~0.875   | ~0.874           |
| LinearSVC           | ~0.878   | ~0.877           |

> Results are approximate; run `python -m src.evaluate` to reproduce exact numbers
> after training.

## Setup

### 1. Create a conda environment

```bash
conda create -n sentiment-nlp python=3.11 -y
conda activate sentiment-nlp
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

> GPU training: install the CUDA-enabled torch build before the above step.
> See https://pytorch.org/get-started/locally/ for the correct command.

---

## Training

### Train baseline models (Logistic Regression + LinearSVC)

```bash
python -m src.train_baselines
```

Downloads SST-2, fits a TF-IDF vectoriser, trains both classifiers, evaluates
on the validation split, and saves artefacts to `models/baseline/`.

Typical runtime: **< 3 minutes** on a standard laptop CPU.

### Fine-tune DistilBERT

```bash
python -m src.train_distilbert
```

Fine-tunes `distilbert-base-uncased` for 3 epochs with early stopping, saves
the model and tokeniser to `models/saved/`.

Typical runtime: **~20 minutes** on CPU, **~5 minutes** on GPU.

---

## Evaluation

```bash
python -m src.evaluate
```

Runs all three models on the SST-2 validation set, prints a comparison table,
and saves confusion matrices + bar charts to `docs/`.

---

## Running the Streamlit App

```bash
streamlit run app/streamlit_app.py
```

Then open `http://localhost:8501` in your browser.

Features:
- Model selector in the sidebar
- Free-text input
- Colour-coded POSITIVE / NEGATIVE label
- Confidence progress bar
- Inference time display
- Side-by-side comparison when "All Three" is selected

---

## Running Tests

```bash
pytest tests/ -v
```

Tests that require a trained model are automatically skipped if the model
files are not present. Train the models first for full test coverage.
